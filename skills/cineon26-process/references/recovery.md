# 错误恢复与画框、颜色调整

## 先读具体原因

记录受影响来源、当前操作、错误原文和可用恢复按钮。使用 View Failure Details／查看失败原因、Copy Details／复制详情或当前错误提示，不只看红色卡片。成功照片保留结果，继续处理可用项。

| 现场状态 | 操作 |
| --- | --- |
| 导入、Auto 或导出不可用 | 读按钮说明和顶部提示，区分内测权限、选择范围、忙碌队列、未确认分帧、几何、源文件、ICC 和缓存；不要据此重装 |
| 原片仍存在但无访问权限 | 用 Grant Access／允许访问，选择提示的原目录；保留原路径，不把权限问题当文件丢失 |
| 原片确实缺失或移动 | 用 Locate Source／重新定位源文件，或 Browser 的 Locate Folder；核对原件，目录结构不变时可一起找回关联来源 |
| 原片内容已变化 | 找回原文件；若确实要用新文件则明确重新导入，不让旧结果冒充新原片的处理 |
| 不支持、损坏或扫描色彩信息有问题 | 区分具体提示，检查可读性与完整性，保留该项并继续其他文件；不改后缀或乱配 ICC |
| Film / Frame Format 不正确 | 点击照片卡片的胶卷／画幅标签，或使用 Image → Film & Frame／图像 → 胶片与画幅，核对作用范围；分帧照片无需重新导入，改画幅后重新检查区域并 Auto |
| 条带待确认 | 完成 [workflows.md](workflows.md) 的条数、帧数和边界检查，不手改工程跳过复核 |
| 画面和片基重叠或区域无效 | 按下节修框；Crop 不能修复取样区域。当前框有效且正确时可直接 Auto 确认，不必先拖动 |
| 3F ICC 未配置、不可访问或不匹配 | 分别处理：选择缺失项、重新选择原有效文件取得访问、选择正确内容。见 [workflows.md](workflows.md)；不匹配不能靠改名解决 |
| 处理结果需更新或不兼容 | 先保存，恢复所需来源和 ICC，核对分帧与几何；确需 Auto 时只重做受影响项，并注意其会重算调整值 |
| 内存不足、空间不足、处理或导出中断 | 按错误提示减少当前批次或恢复可用资源，再重试受影响项；保存项目，不自动清全部缓存或强退 |
| 偏色但处理成功 | 先核对声明和画框，再用 Color Balance；保留场景灯光，不靠换胶卷或挪片基调颜色 |

源文件、ICC 和缓存是否必须可用取决于当前操作。App 已验证完整缓存时，部分编辑和导出可以继续；重新自动校色仍可能需要原片。ICC 不可用不代表裁切、方向或浏览一律不可用。按实际按钮和恢复提示判断，不能把一个错误扩大成全项目不可编辑。

## 缓存与旧项目

先保存当前项目，保留评分、手调、裁切、方向、快照及组织。重新打开旧项目不应被当作重新校色请求；不要主动重跑整批 Auto。

需要全分辨率画面时，让 App 按当前操作恢复，并等待进度结束。缺少来源时先恢复访问或定位原件；缺少对应 ICC 时按其具体原因恢复。只看到小预览不证明全分辨率结果或导出已经可用。

不要把旧版“切到 100% 就能修复所有导出缓存”当成固定步骤。100% 用来检查像素，是否恢复成功要以实际图像、可用状态和导出结果为准。若提示缓存/历史结果不可恢复，保留错误与版本，继续其他可用项。重新 Auto 会重算它负责的参数，不能冒充保留原编辑的缓存修复。

不直接写缓存、项目文件或偏好设置，不删除收据。File → Clear Cache 是用户管理空间的操作，不作为每次失败的自动恢复。

## 几何：G / D

- **Active Area**：亮绿色虚线，表示有效胶片画面。
- **Film Base**：亮蓝色虚线，负片真实未曝光片基；反转片无此步骤。
- **Crop**：构图工具，独立于上述区域。

1. 核对当前照片和批量选择，退出历史快照预览，查看最新截图。G、D 或工具栏显隐识别区域，开关会记忆；隐藏不会确认区域或应用修改。
2. Active Area 沿真实画面四边放置，避开齿孔、片边、夹具和邻帧。拖动一条边只改变该边；角点固定对角、等比例缩放；框内拖动为平移。角点不是任意透视顶点，不尝试把矩形拉成四边形。
3. Film Base 放在当前帧范围内可见、均匀、未曝光的胶片材料上，与画面分离；避开字、齿孔背光、黑夹具、反光和脏点。不借邻帧片基，不把孔洞白光当片基。
4. 先 Fit 看整体，再放大检查细边。超过 Fit 后可用触控板两指滚动或按住空格拖动画布；这是移动视野，不是移动画框。Fit 恢复居中。工具不支持组合拖动时使用可用的滚动平移，不改用户显示器布局。
5. 每次松手检查预期对象和边界。误拖用 Command-Z；底部 `Reset Geometry`／重置识别区域恢复已保存的初始位置。它不同于 Fit、Reset Crop 和照片右键的全图 Reset。
6. 内容正确且框有效时，待复核照片可直接 Auto。实际改框后出现“区域已修改，尚未应用到校色”，用 `Reapply Auto Color`／重新自动校色，等待结束后复查。不通过无意义挪一像素解锁，不把隐藏框当确认。

G/D 在已裁切视图上显隐几何，不会取消裁切、自动展开完整原片。需要调整裁切外的边界时，先保存快照；通过裁切工具查看完整来源，必要时明确重置裁切、修框，再恢复用户所需构图，不静默丢弃已有裁切。

## Color Balance

初步处理中，RAW 有明显偏色时先核对 Film、Frame Format、Active Area 和负片 Film Base，再开启 Color Balance／色彩平衡。没有手动中性参考时采用 Auto；已有用户参考与强度时保留，不把其他照片的值套来。等待更新，在 Fit 与 100% 下比较；明显恶化时恢复原设置。没有上游待更新提示时无需再运行顶部 Auto。

多选开关会统一开启或关闭可处理照片，每张保留各自的参考与参数，整批可一步撤销。混合状态先读提示，确认作用范围；强度、吸管等单图控件不能推定会批量应用。单张偏色只改该张，不因“同卷”默认全开。

日落、蓝色阴影、舞台灯光可能属于场景。用户确认是场景本色时保留，并撤销该张的颜色异常标记；不要扩展成同型号所有照片的结论。进一步主观调色按用户要求。

## 裁切、方向与重置

有原始预览即可 C 裁切，尚未校色也可操作；多画面来源先确认分帧。正在处理的当前照片暂不可改动时等待。Film Ratio、Free 或固定比例以实际界面为准；保留片边时用 Free 调整，不靠改 Active Area 实现构图。

裁切实时生效；C、Enter、Done、Esc 都只是收起工具，Esc 不撤销。误操作用 Command-Z；Reset Crop 清除裁切与裁切旋转。Done 后预览应保留裁切，G/D、HDR、沉浸模式不能当作清除裁切的办法。导出需选 Cropped Area 才应用裁切。

照片右键 Reset 会清除多项编辑并回到原始预览，不是轻量修框或缓存恢复。已有用户编辑时不要把它作为常规排错。需要保留一个可回退版本时先保存快照。

## 三色失败组与重试

RGB 失败先核对同一帧的 R/G/B、自然排序、缺失曝光、几何与匹配平场；同组三张共享区域，切换核对，其他组和白光图保持独立。修改有效后用普通 Auto Color 只重试该组。真正过曝、跨帧或配准无法成立时记录需补拍/重拍，不承诺移动片基能修复一切。

相同错误默认最多两次有依据的修复重试；新证据出现后可继续。每次应有明确原因或状态变化，不循环点击。工具找不到窗口时刷新状态、重连明确 App、尝试可见替代控件；仍无法操作就保存能保留的工作并记录工具限制，不将其伪装成照片处理成功，也不强退或擅改用户桌面。
