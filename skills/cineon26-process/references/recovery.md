# 编辑与错误恢复

## 从当前提示判断

记录受影响照片、操作、错误原文及可用按钮。打开 View Failure Details／查看失败原因，不只看红色卡片。一次失败不代表全项目不可用；成功结果保留，继续其他来源。

| 现场 | 恢复动作 |
| --- | --- |
| 导入、Auto、编辑或导出不可用 | 读按钮说明和提示，区分选区、队列、内测权限、区域复核、来源、ICC 与缓存；不直接重装 |
| 原片存在但无读取权限 | 使用 Grant Access／允许访问，选择提示的原目录 |
| 原片移动或缺失 | 使用 Locate Source／重新定位，或浏览器 Locate Folder；核对真正原件，目录结构一致时可恢复关联来源 |
| 文件与项目记录不一致 | 保留编辑，找回原件；若要使用新内容则重新导入，不改名或手改工程绕过校验 |
| 不支持、损坏或扫描色彩信息不兼容 | 按具体提示检查来源及完整性，保留失败项；不猜 gamma、乱配 ICC 或修改后缀 |
| Film／Frame Format 错误 | 从卡片菜单改正声明，核对实际选区；等刷新或按提示复核区域。仅改项目内名称不重算 |
| 多画面或待分帧 | 按 [workflows.md](workflows.md) 检查条数、帧数、边界；不要仅拖一个框覆盖多张照片 |
| 画面／片基区域无效或重叠 | 按下节调整识别区域，再应用；Crop 不能修复取样区域 |
| 旧项目提示非矩形区域 | 保存原工程；确需重新处理时才用“转换为矩形”，复核后 Auto；不为浏览旧结果主动转换整批 |
| 3F ICC 缺失、无权限或不匹配 | 区分缺文件、重新选择授权和内容错误，按 workflows 的指定来源恢复 |
| 结果缺失、待更新或不兼容 | 先保存，恢复所需来源与 ICC，等待按已保存编辑重建；确需 Auto 时只重做受影响项 |
| 导出提示保存参数无法复用 | 保留工程副本和旧结果；若提示要求重新处理，只对受影响照片 Auto 后核验一次。相同错误仍出现则记录具体模式和格式并停止该分支，不用可见预览冒充成功，不擅自把 HDR 交付改成 SDR |
| 内存、磁盘不足或处理中断 | 等队列稳定并保存，减少后续批次或恢复资源，再重试受影响项 |
| 成功但偏色 | 先检查声明与识别区域，再用 Color Balance；保留场景灯光与用户已有参考 |

权限与定位不同：找到位置后仍可能需要授权原目录。同名不证明同内容。完整缓存已验证时部分编辑和导出仍可继续，不能把来源或 ICC 的一个提示扩大为所有操作都失效；小预览也不能证明全分辨率已可用。

## 识别区域与视野

G 或工具栏显示／隐藏识别区域。绿色 Active Area 是有效画面，蓝色 Film Base 是负片的未曝光片基；反转片无片基步骤。Crop 是另一套构图范围。隐藏框不会确认或应用变化。

1. 确认当前照片、实际选区，并退出快照预览。Fit 查看完整来源，再放大边缘；切图、缩放或窗口变化后重新取截图和坐标。
2. 绿色区域沿真实画面四边放置，避开片边、齿孔、夹具与邻帧。拖边只改该边，拖角固定对角；默认自由调整，Shift 拖角保持比例，框内拖动平移。不能把矩形角点当任意透视顶点。
3. 蓝色区域放在当前帧内均匀、未曝光的胶片材料上，与有效画面分开；避开文字、孔洞背光、黑夹具、反光与脏点。不能借邻帧或以白光当片基。
4. 提示遮挡拖点时缩小或平移。超过 Fit 后双指滚动或空格拖动移动视野；工具不支持组合拖动时用滚动。Fit 明确回到居中全图，不改用户显示器布局。
5. 松手后检查实际边界。误拖用 Command-Z；Reset Geometry／重置识别区域恢复保存的初始位置，与 Fit、Reset Crop 和全图 Reset 不同。
6. 框正确但待复核时可直接 Auto，不必先制造一次拖动。实际改框出现“区域已修改，尚未应用到校色”后，用“重新自动校色”，等完成再检查画面与失败状态。

G 临时展示完整图片，隐藏后恢复已保存裁切，不改变导出范围；不需要先清除裁切。继承色彩的子帧仅在明确 Auto 时独立重新估计。旧区域转换后，重置识别区域的右键菜单可恢复转换前区域，不等于恢复整个项目。

同张照片 Auto、编辑或缓存更新后应保留放大倍率与查看位置；Fit 是主动操作。画面检测缩放设置影响下一次自动检测，不修改既有手工框，不等于输出裁切；通常保持现值，仅在用户要求时调整全局设置并记录。

## Color Balance 与深度校正

明显整体偏色先核对 Film、Frame Format、画面和片基，再开启 Color Balance／色彩平衡。无手动参考时使用 Auto，已有用户参考及强度则保留。等待结果更新，查看实际照片；开关处理中暂时禁用或保持旧显示时不要连点。没有上游待应用提示，无需再点顶部 Auto。

多选开关可统一开启／关闭已就绪照片，各自保留参考和参数，整批可撤销。强度与吸管等单图控件不能推定会批量应用。单张异常只处理该张；同卷不意味着一律开启。日落、蓝色阴影、彩色灯光和用户确认的场景本色不应被强行中和。纯片基片段无需精细调色；先查看完整来源和细节，不能把低反差、欠曝或单色场景仅凭缩略图判为空白。

对提供 Depth Correction／深度校正的彩负，普通平衡后仍有明显异常时可尝试该开关，再比较改善与损失；不是每张彩负默认全开。不可用类型按真实控件处理，不换胶卷类型来解锁。

T 或中性吸管可在有可靠依据的中性区域取样。阴影、染色灯光、片基和剪切高光不自动是中性点。没有可靠参考就保留自动估计；强度 0–100 控制校正程度，Auto 恢复自动参考。

SDR／HDR 共用 Color Balance 开关、手动中性参考与强度，首次建立另一模式也沿用该选择；两种模式分别保留影调与后期编辑。修改共享平衡会影响两套结果，不能只看控件同步就认定两种实际画面都已更新。切换后等待完成并比较各自预览。

彩色 3F 同样提供独立色彩平衡。已收录彩色胶卷初次处理默认关闭，未收录彩色胶卷初次处理默认 Auto、强度 100；旧项目沿保存状态恢复。它不能代替正确 ICC。黑白负片相关彩色控件不可用是正常限制。

## 参数复制与其他编辑

复制参数适合用户希望把一张参考照片的处理设置应用到兼容目标时使用。先查看参考实际效果，再点“复制参数”；选择一张或多张目标并核对数量、胶片与处理类型，点“应用参数”。未校色目标也能使用参考参数出图；不兼容项按提示处理，不换声明凑兼容。

应用保留目标各自的识别区域、裁切、方向与评分；色彩、基础、平场和后期设置依参考应用。整个操作可一次撤销／重做，已有相同参数的照片可能跳过。检查每个目标的实际亮度和颜色，不把相似胶卷当作曝光与拍摄条件相同。默认初步处理仍逐张 Auto，复制不是自动估计的替代。

- Basic 的黑白点、中间调、胶片对比度按当前图提供的控件调整；例如 SDR 相机反转片的部分基础控件不可用，不表示处理失败。标题 Auto 与通道 Auto 作用范围不同，按说明选择最小重置范围。
- Post-processing 总开关决定曝光、高光／阴影、RGB 色阶和亮度曲线是否应用；关闭保留值，展开面板不等于开启。多选总开关与单图数值作用范围分开。
- 顶部 Auto 会重新估计它负责的参数，不用于轻量刷新用户手调。需要回退时先存快照或项目副本。
- 保持白色齿孔独立于后期，只影响可识别齿孔的预览及导出；没有可用齿孔时不强行改框制造变化。
- Y 或对比按钮查看原始预览与当前结果；三色可检查 R/G/B 和合成图。对比不应改变编辑，继续操作前回到当前结果。
- SDR／HDR 控件对选中的照片批量切换；每次核对选区。切换不是重复 Auto，也不能以开启后期代替 HDR。

## 裁切、快照与重置

有原始预览即可 C 裁切。新裁切默认 Free，既有比例保留；Film Ratio 或固定比例按用户构图选择。裁切实时生效，C、Enter、Done、Esc 收起工具，**Esc 不撤销裁切**。误操作用 Command-Z；Reset Crop 清除裁切及裁切旋转。收起后复查真实范围。

进出裁切保留显示尺度和查看位置；全图与裁切的 Fit 基准不同，显示百分比变化不一定是图片实际缩放。G、HDR 或沉浸显示不会主动清除裁切。导出用 Cropped Area 才应用构图；无裁切时不会自动去片边。

照片右键 Reset 会清除多项编辑并返回原始预览，不能用作轻量修框或缓存恢复。快照仅预览不改当前图，Restore 才恢复保存状态；完整保存与导出流程见 [delivery.md](delivery.md)。

## 缓存、重开与中断

先保存项目，保护评分、手调、裁切、方向、快照和组织。重开项目不是重新校色请求。打开或切图时可按保存编辑后台重建缺失像素；等待实际状态恢复，不把旧缩略图当作成功，也不强制重跑 Auto。

Settings → Cache 显示实际占用及所有项目共用的上限（默认 50 GB）。129 本地界面提供“其他项目”与“所有项目”的清理范围；不同版本如显示当前项目清理，按真实标签和确认文案判断。清理不是失败后的默认修复，调整上限或位置须在用户空间管理要求范围内。

已获清理授权时，先核对作用范围、当前项目及其他项目。优先只回收本次任务可重建的缓存；界面无法安全限定范围时先停止扩批，说明具体限制，不改工程或全局缓存目录绕过。正在使用的缓存可能被保留，以操作后的用量为准。保留原片、项目、ICC、快照、成片及收据；缓存清理后允许重建耗时。

100% 用于查看像素，不是通用修复按钮。已保存结果不可恢复时记录错误与版本，继续可用项；Auto 重算不能冒充保留编辑的重建。SDR 预览重新出现也不证明 HDR、快照或全分辨率导出已恢复，分别核对所需操作。

RGB 失败先核对完整成员、自然排序、曝光、配准、画框与平场。修复后只重试受影响组；真正过曝、跨帧或缺曝光要补拍。残帧和空白单独记录，不能硬套完整画面以消除失败卡片。

重试应有新的依据或状态变化，相同错误不循环点击。工具找不到窗口或点击无响应时刷新状态、重连准确 App；窗口明确提供 Raise 时可先激活，再核对操作是否生效。残留菜单如明确提供 Cancel 动作可先收起再读取窗口。仍无法操作时保存可保留工作并报告工具限制，不强退或擅改桌面。
